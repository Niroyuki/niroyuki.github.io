確率五目並べのルール

1. 盤面と座標

13×13 マスの盤面を使用します。横軸はエクセルのように A〜M、縦軸は 1〜13 で表記されます。

2. ２種類の確率駒

プレイヤーは手番ごとに以下の2種類の駒を交互に打ちます：

  • 黒の駒: 「90%黒 / 10%白」 と 「70%黒 / 30%白」
  • 白の駒: 「90%白 / 10%黒」 と 「70%白 / 30%黒」

3. 手番の流れと観測権（各5回）

  1. 盤面の空きマスを選び 【駒を置く】（重ね合わせ状態）。
  2. 駒を置いた後、【観測する】 か 【観測せず終了】（スキップ）を選択します。
  3. 観測権は各プレイヤー対局中5回までしか使えません。

4. 観測結果と勝利条件

【観測する】を押すと、盤面上すべての駒の色が一斉に収束します。

  • 縦・横・斜めのいずれかに5連が並べばその色の勝利！
  • 5連が揃わなければ駒は元の確率（重ね合わせ）状態に戻り対局を続行します。
